# Инструкция по подключению VK-бота и работе уведомлений

Единственным внешним мессенджером платформы является **ВКонтакте (VK)**.

## 1. Архитектура уведомлений и два режима работы

```text
Бизнес-событие в Java Backend (Заявка / Модерация / Знакомство / Тикет / Чат / Напоминание)
        │
        ▼
NotificationService (сохраняет In-App уведомление в таблицу notifications)
        │
        ▼
VkIntegrationService
        ├── Режим TEST_LOG (по умолчанию, без токена):
        │   Записывает факт доставки со статусом SENT_TEST_LOG и позволяет проверять команды через встроенный терминал.
        │
        └── Режим REAL (при наличии VK_GROUP_ID и VK_COMMUNITY_TOKEN):
            Вызывает метод API ВКонтакте messages.send + слушает входящие коды и команды через VK Bots Long Poll API.
```

## 2. Как привязать аккаунт пользователя к VK-боту

В соответствии с правилами платформы ВКонтакте (`dev.vk.com`), бот сообщества не может написать пользователю первым без начатого диалога. Поэтому реализован безопасный протокол одноразового кода:

1. Войдите в аккаунт на платформе и перейдите в раздел **Уведомления и VK-бот** (`/notifications`).
2. Нажмите кнопку **«Сгенерировать код привязки»**. Backend создаст одноразовый код вида `SP-123456` со сроком действия 15 минут.
3. Откройте диалог с сообществом ВКонтакте (или используйте встроенный интерактивный терминал команд VK-бота на той же странице для локальной проверки без токена) и отправьте код `SP-123456`.
4. Бот проверит код, свяжет ваш `vk_user_id` с профилем платформы и пришлёт подтверждение.
5. В любой момент вы можете приостановить доставку уведомлений в VK или полностью отвязать аккаунт.

## 3. Доступные команды VK-бота

* `SP-XXXXXX` — привязать аккаунт платформы по одноразовому коду;
* `Мои мероприятия` (или `events`) — получить список ваших ближайших подтверждённых тренировок и встреч;
* `Статус` (или `status`) — проверить привязанный профиль и состояние уведомлений;
* `Отключить` (или `stop`) — приостановить внешние уведомления в VK;
* `Включить` (или `start`) — возобновить уведомления в VK;
* `Помощь` (или `help`) — вывести список доступных команд.

## 4. Как подключить реального бота сообщества ВКонтакте (`VK_BOT_MODE=REAL`)

1. Создайте сообщество ВКонтакте (или откройте существующее, где вы администратор).
2. Перейдите в **Управление $\rightarrow$ Сообщения** и включите **Сообщения сообщества** и **Настройки для бота (Возможности ботов: Включены)**.
3. Перейдите в **Управление $\rightarrow$ Работа с API $\rightarrow$ Ключи доступа** и создайте ключ с правами на **управление сообществом** и **сообщения сообщества**.
4. Перейдите во вкладку **Long Poll API**, включите его (версия API `5.199`) и в разделе **Типы событий** отметьте галочкой **Входящее сообщение (`message_new`)**.
5. Укажите в файле `.env`:
   ```env
   VK_BOT_MODE=REAL
   VK_GROUP_ID=ваш_числовой_id_группы
   VK_COMMUNITY_TOKEN=ваш_ключ_доступа_сообщества
   VK_CLUB_URL=https://vk.com/clubВАШ_ID
   ```
6. Перезапустите стек `docker compose up -d`.
