# Регламент работы Системы тикетов и Чата технической поддержки

В платформе реализованы два самостоятельных, но согласованных канала взаимодействия пользователя с администраторами:

## 1. Чем отличаются Тикеты и Чат техподдержки

| Характеристика | Система тикетов (`/support` $\rightarrow$ Тикеты) | Чат технической поддержки (`/support` $\rightarrow$ Чат) |
| :--- | :--- | :--- |
| **Назначение** | Официальные жалобы (на мероприятие, пользователя, организацию), проблемы с аккаунтом или технические обращения, требующие расследования и фиксации результата | Быстрые вопросы, уточнения по работе платформы и консультации в свободном диалоге |
| **Структура** | Уникальный номер (`TCK-XXXXX`), категория (`TicketCategory`), тема, привязка к целевому объекту (`targetType`/`targetId`), вложения, резюме решения | Непрерывная лента сообщений между конкретным пользователем и администраторами платформы |
| **Статусы** | `OPEN` $\rightarrow$ `IN_PROGRESS` $\leftrightarrow$ `WAITING_FOR_USER` $\rightarrow$ `RESOLVED` $\rightarrow$ `CLOSED` | `ACTIVE` (ожидает ответа), `ANSWERED` (ответ дан), `RESOLVED` |
| **Уведомления** | При каждом ответе администратора и смене статуса отправляется In-App и VK-уведомление | При каждом ответе администратора отправляется In-App и VK-уведомление + индикатор непрочитанного ответа |

## 2. Подача жалобы прямо из контекста объекта
В карточке любого мероприятия (`/events/:id`), профиля пользователя (`/users/:id`) и страницы организации (`/organizations/:id`) расположена кнопка **«Пожаловаться»**, которая открывает форму создания тикета с автоматически предзаполненными `targetType`, `targetId` и темой обращения. Администратор при просмотре такого тикета видит прямую кнопку перехода к объекту жалобы.
